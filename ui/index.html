Claudeguard

Прокси и kill switch для Claude

Нет доступа к панели

Откройте её ярлыком Claudeguard или командой claudeguard ui: ссылка содержит ключ доступа.

Серверы

    Нажмите на сервер, чтобы пустить Claude через него. Переключение происходит сразу, без перезапуска Claude.

    Защита

    Kill switch
    Пускать через VPN на этом компьютере Когда VPN включён, Claude может идти и через него. Без VPN всё по-прежнему только через сервер выше.
